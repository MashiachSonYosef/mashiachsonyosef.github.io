# The Tabernacle

A dark-mode Hebrew reader and English workbench for the Book of Genesis, with word-level glosses and exact commentary attachments (Rashi, Onkelos).

Currently a proof slice covering Genesis 1:1–1:2, with the full 50-chapter navigation scaffold in place.

**Live site:** https://mashiachsonyosef.github.io/

- `index.html` — redirects to the reader
- `genesis-book-reader-v4/` — the reader (HTML/CSS/JS) and its data files
