# Addendum — 2026-08-26, later the same day

The owner reviewed the rule change described in the previous note and
ruled it reverted (website repo commit c5c7ebf1). His ruling, in
substance: antiquity is a concrete, neutral criterion this project chose
in the open; "the catalog's own order" defers the choice to an ordering
whose basis this project has not examined — a bias it cannot name.
Rule v4 (oldest source year leads) stands; rule v5 is withdrawn.

The two asks in the previous note stand unchanged, and the ruling makes
them the only path: the cross-language collisions and the homograph
defaults exist under either ordering, so no reader-side rule will be
attempted again. What would actually fix the default glosses is the
data itself —

- a language tag per route (or per single-language M source), and
- a targum-aligned occurrence-level source, as the Tanakh interlinear
  already is for Hebrew.

Until that cargo exists, the served pages print what antiquity picks
and the masthead says exactly where the readings come from.
