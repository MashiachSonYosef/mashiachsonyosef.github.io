# The default toggles' first build: integration and independent review (14 November 2026)

Built on ledger v1 + v1.1 in the work tree (uncommitted). Integration: every check green; at rest only the plan's MACULA fills differ from live (11 lines in Amos, Ruth and Psalms). What follows is what the reviewers and the critic found; each is fixed, or answered, in the next build.

- **[should-fix]** `zone.html:3785` When the book file fails after a press (dfltAnswer's reject handler only repaints the pills), one state draws the line by two rules. Lines built before the press keep the old state's lines: the 212 STEP fills, still marked data-layer=second, src=macula. defaultAt (5656-5662) then reads first=UBS with no picks, and with STEP as the second it returns null. So sections built afterwards, and every card, show today's line without the fill. The note says «the line stands as it was», which is true only for sections built before the press.
  - *Scenario:* Psalms, fresh profile, psalms.bin aborted with route. Build sections up to 10:5, press UBS (the pill says «could not be fetched»), then build up to 18:51. 10:5:2 still reads «ways his» [M3, layer second], but 18:51:1 reads «tower» [M14], the pre-fill line.
