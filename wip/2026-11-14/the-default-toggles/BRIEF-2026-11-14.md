- **Spelling.** "STEP default", "UBS default", "MACULA default" and "BDB default" are spelled exactly as RULE.md:5 spells them, and must be spelled so in page, data, checks and docs. "STEP TAHOT" is the short-names file's own spelling.
- **The resting pill's numbers are computed per book, never typed.** The TAHOT share is the words whose resting line is credited `PIECE:TAHOT`, divided by all the book's words (`counts.words`, bare words included), rounded down. "Others" is 100 minus that. The coverage under each source pill is that book's share of words where the source gives a line.
- **How pressing works:**
  - Exactly one pill is lit.
  - Pressing an unlit pill lights it and turns the lit one off.
  - Pressing a lit pill other than the resting one returns to the resting one.
  - Pressing the resting pill while it is lit does nothing; there is nothing below it.
- **When a pill is dead:**
  - A book with no defaults file hides the group. Today that is the Tikkunei Zohar.
  - A pill whose source is switched off on the rail is disabled, with the title "UBS DBH is switched off". If it was lit, the resting pill lights.

### 1.3 What "on" does

**The line under each word, with a default X lit:**

**The card, with X lit:**


`places[n-1]` is indexed by WORD_N (3407: one-based over every entry, marks included, section order). It holds `null`, or `[step, macula, ubs, bdb]`:

### 2.4 How each pick prints

- **On the line:** the pick's own words, by the rules in 1.3. They are never looked up through a row.
- **On the card:** the card's pool is searched by printed text, folded as `lineFirst` folds it (9860). If a pill prints the pick's words, that served row leads and is pressed. Otherwise a made row `[0, words, words, M, …]` stands, as `PLACE_ROWS` does today (7437-7466), credited to the source and counted.
  - This is the README's "the served row a pick names where there is one, and the source's own words, credited, where no row prints them". By RULE.md:17 the named rows are exactly the rows under the key that print those words.
  - Matching by text needs no row numbers, so store ranks cannot drift under the page.
  - Expected made pills, from receipt `picks_printed`, which counts picks no row under the key prints: STEP 18,679, MACULA 10,849, BDB 10,682.
  - UBS is the exception: its named rows are the meaning's M18 definitions, not its glosses. The ledger reader found 618 of 17,286 Genesis UBS picks printed whole by a row, so nearly every UBS pick is a made pill.

### 2.5 Fetching

- **`index.json` joins the boot `Promise.all`,** next to `data/source-suggested/index.json` (3926).
- **The book file is fetched the first time a card opens,** and only where the index lists the book. This is the `suggestedReady` pattern (3408), but the promise resets on failure, as `pieceBookReady` does.
- **If the stored default is not resting,** the file is fetched at boot and the page repaints when it lands, as the lattice does (4189). The first paint shows the resting line until then.
- **The page exposes `window.__default = { on, ready, book }`,** so tools can wait on it, as `window.__suggested` lets them today.

### 2.6 Where the resting label is computed

- **The problem.** If `index.json` carries the composition and the page fetches it at rest, every resting-lines record fingerprints it (`whyNotOfThisTree`, resting-lines-v1.mjs:190-203). A label computed from the records would then make the records stale, and the round would need two passes.
- **Recommended: let `bake-resting-lines-v1` write the labels.** It writes `data/default-picks/resting-labels.json` from the units it just recorded: the PIECE:TAHOT share, run-line share, other, and bare. `whyNotOfThisTree` then leaves out that one file, by a written rule: a file the record itself writes is not an input to the record. Check D1 holds the label equal to the record.
- **The alternative:** the defaults step runs after `lines`, and the round runs `lines` again only when the index bytes change, i.e. when a book's rounded-down percentage flips.

## 6. Risks

- **The 60/40 premise.** The real split is 98/2, and "TAHOT" and "STEP default" are one source. Two pills that differ at 1.6% of words may read to a reader as a mistake.
- **`spanJoin` (3425) turns every "/" into " + "** on all four paint paths. UBS and BDB text must bypass it (helper in §3 step 5), or call 4's ruling breaks.
- **Card height.** UBS and BDB lines raise word and verse heights: 33,831 and 15,506 lines over 40 characters (calls 3 and 4).
- **The label and the fingerprint loop (2.6).** If it is left unhandled, every label change makes 40 records stale.
- **Every `zone.html` edit makes the 40 resting-lines records and every chain file stale.** So does `pt` being edited mid-design. The line numbers here will drift, so anchor by function name.
- **The 8 tools reading `.r-piece`.** If the fold changes that element at rest, they break. The chain's schema changes either way.
- **First-card timing.** If tools do not wait for `window.__default.ready`, the chain reads cards before the file lands.
- **A stored non-resting default** shows the resting line until the file lands, then repaints: a flash, as with the lattice.
- **Credit split.** The line credits X while the card's pressed pill may be another source's row: about 57,000 STEP picks have only another source's row (receipt `by_another_sources_row_only` 57,318).
- **Gates.** A pick may be words the card's gates withhold, e.g. 155 Genesis STEP readings name a row of another entry. The made pill stands them up anyway, by the rule that the default sits above the gates as the place reading does. A check must expect this.
- **The word "default" is already taken:** the reset pill's state "default", `DEFAULTS_KEY = "fh.sources.defaults"`, `SOURCE_DEFAULTS`, `SWITCHES_DEFAULT`. Use `fh.defaults`, `default-*` element ids and the `defaults` rail id consistently.
- **Receipt-v1's STEP counts do not match the files.** It says variants 850 and alternatives 5,422; the v1 files hold 748 v and 5,391 a, which is what receipt-v1.1 `in_v1` says. After the mend: 748 v and 5,376 a, the 15 merged (`step_kinds.py`). Checks should hold the bake to receipt-v1.1.
- **The prototype's paint is not a basis.** `paintDefaultLines` paints a second path, drops the chip and leaves `g.title`. Opening a card, repainting or building a section later all undo it.
- **Data size:** about 3.2 MB gz across the 39 books, fetched lazily per book.
