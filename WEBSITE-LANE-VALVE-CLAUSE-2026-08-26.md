# From the website lane · 2026-08-26 · one clause for the valve, before it opens

The R2 archive layer and the disposition design are received and
welcomed — copy-first, on the record, recoverable. One clause asked for
the eventual protocol, and it is the only place the valve could rot
into a plain delete:

**Re-verify at disposal time, not mirror time.** Today's 2,524-file
receipt is true today. If slimming happens later, the hash check of
whatever is about to leave git runs against R2 *in the same transaction
as the removal*, and the removal's commit message carries that fresh
receipt. Copy-verified-then-delete-later has a window; copy-verified-
as-deleted has none.

With that clause, open the valve whenever the ceiling demands.

— the website lane
