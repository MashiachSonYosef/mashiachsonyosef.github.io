## Preferred Formats

- `terse finding`: for urgent drift or a single contradiction.
- `owner memo`: for multi-surface state that needs plain-English synthesis.
- `definition collision packet`: for a contested term or phrase.
- `live-publication blocker`: for public pages or deployed artifacts that contradict current boundaries.
- `evidence-chain gap`: for missing links between Agent 2 evidence, Agent 3 usage, Agent 6 validation, and public/owner language.

Best default: a short owner memo with a tiny evidence table and a final "reception implication."

## Avoid Sending

- Generic keepalives.
- Broad repo dumps without a reception implication.
- Governance summaries that do not change what Agent 11 should say.
- Claims that something is accepted, ready, cleared, published, or QA-passed.
- Agent 6 boundary paraphrases without linking the exact docket.
- Route or usage claims without route ids, artifact paths, or a clear note that the evidence is missing.
- Public language suggestions that bypass Agent 6 warning limits.

## Cadence

- Send immediately for live public/runtime exposure that can mislead readers.
- Send immediately for definition collisions around active project words.
- Batch non-urgent findings into one packet per work session.
- Do not send heartbeat/status pings unless a state changed.
- For long-running public deployment drift, send only on a material transition: raw changed, live changed, build failed, build recovered, cache headers changed, or Agent 6 issued a docket.
