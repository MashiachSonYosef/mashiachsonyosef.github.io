how to recompute any number on this page
the function
sha256 over the UTF-8 bytes of the string, with no normalisation, no trimming and no case folding. Printed as the first 12 hex digits; all 64 for every one of them are in chain-v1.json.gz beside this page.
a word
the Hebrew as the page prints it — vowels, cantillation and all, the licensed text untouched. The pale number beside it is its consonantal key.
a reading
the reading's English text as the card prints it. The pale number after it is the label of the oldest source carrying that reading; where more than one carries it, the file lists them all.
what it proves
custody: the bytes served are the bytes received, and the line from a word to a reading goes where this site says it goes.
what it does not prove
that any dictionary is right. A fingerprint is a fact about a file, never about the truth of what the file says.
